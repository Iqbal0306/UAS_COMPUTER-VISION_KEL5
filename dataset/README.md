# Dataset

- `raw/`: 26 gambar terkurasi yang dipakai untuk evaluasi program.
- `raw_file/`: sumber salinan dataset terkurasi.
- `raw_web/`: gambar tambahan yang belum dimasukkan ke eksperimen utama.
- `annotations/corners.csv`: anotasi empat sudut dokumen. Isi melalui `python src/annotate.py`.

Kelas berdasarkan nama file: `normal_`, `miring_`, dan `redup_`.
